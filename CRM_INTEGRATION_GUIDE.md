### 3. **Перевод формы на хинди**
Переведены все тексты формы заказа:
- **Заголовок**: "ऑर्डर दें" (Оформить заказ)
- **Подзаголовок**: "फॉर्म भरें और हम आपसे संपर्क करेंगे" (Заполните форму и мы свяжемся с вами)

- **Поле телефона**: "फोन नंबर" (Номер телефона)
- **Плейсхолдеры**: "अपना नाम दर्ज करें", "+91 XXXXX XXXXX"
- **Кнопка отправки**: "ऑर्डर करें" (Оформить заказ)
- **Текст загрузки**: "भेजा जा रहा है..." (Отправка...)
- **Сообщения**: успех, ошибка, валидация на хинди

### 4. **Ограничение ввода телефона для Индии**
Добавлены настройки валидации в `appConfig.ts`:
```typescript
phoneValidation: {
  enabled: true,
  countryCode: '+91',
  minLength: 10,
  maxLength: 10,
  pattern: '^[6-9]\\d{9}$', // Индийские номера начинаются с 6-9
  errorMessage: 'कृपया 10 अंकों का वैध फोन नंबर दर्ज करें'
}
```

### 5. **Расширение настроек CRM**
Добавлены полные настройки API в конфигурацию:
```typescript
api: {
  enabled: true,                    // Вкл/Откл отправку в CRM
  leadEndpoint: 'https://api.pwa.uniaffcrm.com/add_lead',
  ktCampaignId: 'default-campaign', // ID кампании
  ktDomain: 'Mark',                 // Домен/байер
  timeout: 10000,                   // Таймаут запроса (мс)
  retryAttempts: 3,                 // Количество попыток
  retryDelay: 1000,                 // Задержка между попытками (мс)
  logErrors: true                   // Логирование ошибок
}
```

## 🚀 Функциональность

### **Форма заказа**
- **Локализация**: Полностью на хинди
- **Валидация телефона**: 10-значные индийские номера (начинающиеся с 6-9)
- **Автоматическое ограничение ввода**: Только цифры, максимум 10 символов
- **Retry логика**: 3 попытки отправки с задержкой 1 секунда
- **Таймауты**: 10 секунд на запрос

### **Отправка данных**
Формат отправляемых данных:
```json
{
  "name": "Имя пользователя",
  "phone": "9876543210",
  "ktCampaignId": "default-campaign",
  "ktDomain": "Mark"
}
```

### **Настройки для разных кампаний**
Для создания разных PWA под разные кампании, измените в `appConfig.ts`:
```typescript
api: {
  ktCampaignId: 'campaign-name-here', // Уникальный ID кампании
  ktDomain: 'BuyerName'               // Имя байера
}
```

## 🛠️ Управление

### **Отключение CRM**
```typescript
api: {
  enabled: false, // Отключает отправку в CRM
  // ...
}
```

### **Изменение языка**
Все тексты формы находятся в `appConfig.orderForm` и легко изменяются

### **Настройка валидации**
Параметры телефона настраиваются в `appConfig.phoneValidation`
